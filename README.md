# [MDIA2010A3Cecilia.github.io](https://cch912.github.io/MDIA2010A3Cecilia.github.io/assignment3/assignment3_index_DS.html)
This is an interactive web experience project. The protagonist will move between the three main pages: DreamSync, Dream Commons, and Free Dreamers.
Users can unlock and explore the content of different pages step by step by clicking the interactive buttons on the web page. 
Project Content 

DreamSync (assignment_index_DS.html)
It is a initial page.
Click from top to bottom in sequence, and it will redirect to the Dream Commons page.
Click the Back button at the top right corner, and you can return to DreamSync.
Click the last interactive button, and it will lead to the transitional page of DreamSync → Free Dreamers.

Dream Commons (assignment_index_DC.html)
The user enters from the DreamSync page.
They can return to DreamSync by pressing the Back button. 

DreamSync to Free Dreamers (assignment_index_DStoFD.html)
It is a transitional page.
Clicking the interactive button will redirect to the Free Dreamers page. 

Free Dreamers (assignment_index_FD.html)
It is a final page.
Here, users complete the entire web interaction experience.
